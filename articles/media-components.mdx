Canvasflow's rich media components let you go well beyond text and static images. You can embed videos from major platforms or upload your own files, add audio streams, drop in interactive maps, build multi-image galleries with animations and captions, and enhance photographs with non-destructive image filters — all without leaving the Article Builder. This guide covers each media component in detail, along with image-level settings that apply across components.

---

## Video Component

The Video component embeds a video in your article either by URL or by uploading a video file directly.

<Steps>
  <Step title="Place the component">
    Drag a **Video** component from the Media section of the Component Panel onto the canvas.
  </Step>
  <Step title="Add a video source">
    In the properties panel, either:
    - Paste the full URL, video ID, or embed code for a YouTube, Vimeo, Facebook, or Vidyard video into the web video field, **or**
    - Use the **Movie Option** to upload a video file from your device.
  </Step>
  <Step title="Configure display options">
    Adjust the available settings to match your article layout.
  </Step>
</Steps>

<Accordion title="Video component settings">
  - **Aspect Ratio** — Set the display aspect ratio for the video. Common options include 16:9, 4:3, and 1:1.
  - **Poster Image** — Upload a still image to display as the default frame before the video plays. This option is only available for uploaded video files (not web videos).
  - **Show Suggested Videos** — Choose whether recommended videos from YouTube or Vimeo are shown after playback ends.
  - **Full Bleed** — Expands the video to fill the full page width, removing padding.
  - **Credit** — Add a credit for the video creator, displayed in the bottom-right corner.
  - **Caption** — Add a text snippet shown beneath the video.
  - **Display On Device** — Choose which device types (mobile, tablet, desktop) show the video. The default is all three.
</Accordion>

## Audio Component

The Audio component embeds audio content from SoundCloud or PodBean into your article using an embed URL or code.

<Steps>
  <Step title="Place the component">
    Drag an **Audio** component from the Media section onto the canvas.
  </Step>
  <Step title="Paste the embed code">
    Copy the URL or embed code from SoundCloud or PodBean, paste it into the **Embed Field**, and click **Apply**.
  </Step>
</Steps>

<Accordion title="Audio component settings">
  - **Caption** — Add a caption beneath the audio player.
  - **Full Bleed** — Stretches the component to the full canvas width, ignoring padding.
  - **Display On Device** — Choose which device types display the audio player. The default is mobile, tablet, and desktop.
</Accordion>

## Map Component

The Map component embeds an interactive Google Map into your article — useful for directions to an event, highlighting a location, or illustrating a story with a geographical context.

<Steps>
  <Step title="Place the component">
    Drag a **Map** component from the Media section onto the canvas.
  </Step>
  <Step title="Set a location">
    Enter a postcode, address, or paste a Google Maps URL or share code into the location field.
  </Step>
  <Step title="Customise the map">
    Adjust the display settings to match your article's design.
  </Step>
</Steps>

<Accordion title="Map component settings">
  - **Zoom Level** — Set how closely the map is zoomed in on the location.
  - **Map Style** — Choose from styles including Google Default, Apple Maps, Greyscale, Subtle Blue, and others.
  - **Caption** — Add a label or description beneath the map.
  - **Full Bleed** — Removes padding so the map spans the full page width.
  - **Marker** — Place a pin on the map to precisely identify the featured location.
  - **Display On Device** — Choose which device types show the map. The default is mobile, tablet, and desktop.
</Accordion>

## Gallery Component

The Gallery component displays a collection of images as an interactive slideshow. Readers can navigate through images manually or let the gallery play automatically.

<Steps>
  <Step title="Place the component">
    Drag a **Gallery** component from the Media section onto the canvas.
  </Step>
  <Step title="Upload images">
    Add images to the gallery using the upload interface in the properties panel.
  </Step>
  <Step title="Configure gallery behaviour">
    Set animation, speed, captions, and other options as needed.
  </Step>
</Steps>

<Accordion title="Gallery component settings">
  - **Speed** — Controls the transition speed between images.
  - **Autoplay** — When enabled, the gallery advances automatically as soon as it comes into view. When disabled, readers navigate manually using swipe or the navigation dots.
  - **Animation** — Choose **Slide** (images move in from the side) or **Fade** (images dissolve into each other).
  - **Direction** — When using the Slide animation, choose between horizontal (left-to-right) or vertical (top-to-bottom) transitions.
  - **Aspect Ratio** — Set an expected aspect ratio. Images in the gallery that do not match this ratio are flagged with a warning icon to prompt cropping.
  - **Gallery Caption** — Enable the slider to add a single caption for the whole gallery.
  - **Per-image caption** — Click the speech bubble icon next to any image in the upload list to add a caption specific to that individual slide.
  - **Image Ordering** — Reorder images by dragging them in the upload list using the placement handle.
  - **Full Bleed** — Removes padding so the gallery spans the full page width.
  - **Display On Device** — Choose which device types display the gallery. The default is mobile, tablet, and desktop.
</Accordion>

<Tip>
  You can create a gallery instantly from the canvas by holding the Magic Key (`Cmd` on macOS / `Ctrl` on Windows) and dragging one image component onto another.
</Tip>

## Image Filters

Canvasflow lets you apply Instagram-style photographic filters directly to image components — no image editing software required. Filters are applied non-destructively, meaning you can change or remove them at any time without affecting the original uploaded file.

<Steps>
  <Step title="Select an image">
    Click on an image component on the canvas to open the Image Properties panel.
  </Step>
  <Step title="Open the Filter menu">
    In the Image Properties panel, select the **Filter** menu.
  </Step>
  <Step title="Choose a filter">
    Click the filter you want to apply. The filter is applied to the image immediately on the canvas.
  </Step>
  <Step title="Remove or change a filter">
    To remove a filter, return to the Filter menu and select **None (Default)**. To change it, simply select a different filter.
  </Step>
</Steps>

## Image Crop and Optimisation

### Cropping an image

To crop an image placed in an Image or Gallery component, click the **Crop** icon on the image thumbnail in the properties panel. The cropping tool opens, allowing you to adjust the framing. When using a Gallery component with an Aspect Ratio set, the cropping tool defaults to that ratio.

### Automatic image optimisation

Canvasflow automatically optimises images over 2048px wide when they are uploaded, reducing file size for faster delivery to readers.

### Using the RAW image

If you need the original, full-resolution unoptimised version of an uploaded image — for example, for print-quality export or detailed photography — enable the **Use RAW** toggle in the Image Properties panel.

<Note>
  The Use RAW setting is available on both the Image component and the Full Page Advert component.
</Note>

## Display On Device

Every media component in Canvasflow includes a **Display On Device** setting that controls which device types render that component. The options are Mobile, Tablet, and Desktop, with all three selected by default.

Use this setting to show content tailored to specific screen sizes — for example, displaying a simplified map on mobile while showing a full-featured interactive version on desktop — or to hide components entirely from devices where they are not appropriate.

<Tip>
  Use Preview Mode to verify which components are visible on each device type. Toggle **Hidden Components** in Preview Mode to see ineligible components at 50% transparency rather than hidden, making it easier to audit your layout across devices.
</Tip>

## Full Bleed and Force Full Width

Two image-level width options control how images behave at the edges of the article canvas.

<Accordion title="Full Bleed">
  **Full Bleed** removes the padding that normally keeps content away from the edges of the page. The image (or component) expands to fill the full container width, edge-to-edge. This option is available on Image, Gallery, Video, Audio, Map, Table, and Custom Code components.
</Accordion>

<Accordion title="Force Full Width (Image component only)">
  **Force Full Width** is more aggressive than Full Bleed. It enlarges the image to fill the full device screen width even if the original image is smaller than the screen. Be aware that if the source image is significantly smaller than the device width, pixelation may occur.
</Accordion>
