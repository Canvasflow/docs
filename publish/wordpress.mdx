Canvasflow supports a full two-way integration with WordPress. You can push articles authored in Canvasflow directly to your WordPress site, or pull posts written in WordPress into Canvasflow for styling and multi-channel distribution. Both directions use a dedicated WordPress plugin and a Canvasflow channel connector, giving you a seamless workflow whichever direction your content flows.

## Canvasflow to WordPress (Export)

Canvasflow's export integration lets you publish articles created in Canvasflow directly to your WordPress site. The connection is established through a free plugin installed on your WordPress instance.

### Step 1 — Install the Canvasflow Export Plugin

<Steps>
  <Step title="Install the plugin">
    Download and install the [Canvasflow Export Plugin](https://wordpress.org/plugins/canvasflow-export/) from WordPress.org.
  </Step>
  <Step title="Activate the plugin">
    Activate the plugin through your **WordPress Admin** dashboard.
  </Step>
  <Step title="Open plugin settings">
    Navigate to **Settings** → **Canvasflow Export** in your WordPress admin menu.
  </Step>
  <Step title="Copy your API Key and API Path">
    The plugin automatically generates the credentials needed to connect Canvasflow to your WordPress install. Make a note of both the **API Key** and the **API Path** — you will need these in the next step.
  </Step>
</Steps>

### Step 2 — Add a WordPress Channel Connector in Canvasflow

<Steps>
  <Step title="Open Publication Manager">
    In Canvasflow, navigate to the **Publication Manager** and select the publication you want to connect.
  </Step>
  <Step title="Open publication settings">
    Click the **Settings** button for the selected publication.
  </Step>
  <Step title="Add a new Publish Channel">
    Select **Publish Channels** and click the **+** button to create a new channel.
  </Step>
  <Step title="Select WordPress">
    Choose **WordPress** from the list of channel types.
  </Step>
  <Step title="Enter the connection details">
    Complete the following fields:

    - **Channel Name** — A label for this connector. Typically the name of your WordPress blog, but you can use any name.
    - **Connection Type** — Select **CF Plugin**.
    - **API Key** — Paste the API Key generated by the Canvasflow Export plugin.
    - **API Path** — Paste the API Path generated by the Canvasflow Export plugin.
  </Step>
  <Step title="Add the channel">
    Click **Add Channel**. Your Canvasflow publication is now connected to your WordPress site.
  </Step>
</Steps>

### Step 3 — Publish Articles to WordPress

<Steps>
  <Step title="Open Article Manager">
    Navigate to **Article Manager** and ensure the **WordPress** channel is selected in the channel view.
  </Step>
  <Step title="Publish an article">
    Click the **Publish** button next to any article to send it to your WordPress blog immediately.
  </Step>
</Steps>

## WordPress to Canvasflow (Import)

The **Canvasflow for WordPress** plugin lets you push content from your existing WordPress blog into Canvasflow for styling and multi-channel distribution — no programming knowledge required. There are two parts to the configuration: the WordPress plugin (which controls how content is pushed) and the Canvasflow connector (which controls how content is processed once received).

<Note>
  To enable WordPress-to-Canvasflow publishing, you will first need to [request an API key](https://canvasflow.io/apikey-request) to activate this feature for your account.
</Note>

### Step 1 — Install the Canvasflow for WordPress Plugin

<Steps>
  <Step title="Install the plugin">
    Search for **Canvasflow** in the Plugins section of your WordPress dashboard, or download the plugin directly from [wordpress.org/plugins/canvasflow](https://wordpress.org/plugins/canvasflow/) and extract it to `/wp-content/plugins/canvasflow`.
  </Step>
  <Step title="Activate the plugin">
    Activate the plugin from your WordPress admin dashboard. If you encounter an activation error, see [Troubleshooting: Problems Activating the CF-WP Plugin](#troubleshooting-problems-activating-the-cf-wp-plugin).
  </Step>
</Steps>

### Step 2 — Configure the Plugin

<Steps>
  <Step title="Open the Canvasflow settings">
    In your WordPress dashboard, click the **Canvasflow** tab that appears after activation, then select **Settings**.
  </Step>
  <Step title="Connect to your Canvasflow account">
    Paste your Canvasflow **API key** into the API field and save. The plugin will validate the key and sync with your account.
  </Step>
  <Step title="Select your publication">
    Choose the Canvasflow publication you want to connect to.
  </Step>
  <Step title="Configure the publish settings">
    Set your preferred defaults for the following options:

    - **Default Style** — Choose the Canvasflow style to apply to published articles (this can be overridden per article if needed).
    - **Include Title** — Choose whether the article title is included in content published to Canvasflow. When disabled, only the post body is sent.
    - **Auto Publish** — When enabled, content is automatically published to your connected distribution platform as soon as it is sent from WordPress (for example, WordPress → Canvasflow → your app).
    - **Custom Post Types** — Add any custom post types configured in your WordPress instance to make them eligible for publishing.
    - **Merge Adjacent Paragraphs** — When enabled (the default), adjacent paragraphs are merged into a single Canvasflow component. When disabled, each paragraph is treated as an individual component.
  </Step>
</Steps>

### Step 3 — Publish from WordPress to Canvasflow

Once the plugin is installed and connected, a **Canvasflow Publish Widget** appears in the WordPress post editor alongside the Metatags, Featured Image, and Category panels.

<Steps>
  <Step title="Open a post or page">
    Open any post or page in the WordPress editor.
  </Step>
  <Step title="Use the Canvasflow widget">
    In the Canvasflow Publish Widget, select a style (or leave as default) and click **Publish to Canvasflow**.
  </Step>
  <Step title="Confirm success">
    A **Success** message confirms the article was sent, and its status changes to **In Sync**. If you see an **Error** message, check that the correct API key and publication are selected in the plugin settings.
  </Step>
</Steps>

<Note>
  If the Canvasflow widget is not visible in the editor, enable it through the **Screen Options** menu at the top right of the editor screen.
</Note>

<Tip>
  If you are connected to an issue-based publication, an additional option to publish to a specific **Issue** or **Collection** will appear in the widget.
</Tip>

### Using the Posts Manager and Upload Manager

For more control over bulk publishing, the Canvasflow plugin provides two additional menus within your WordPress dashboard.

<Accordion title="Posts Manager">
  The Posts Manager lists all posts, pages, and eligible custom post types in your WordPress instance.

  1. Select the articles you want to make eligible for publishing to Canvasflow.
  2. Click **Save** to confirm. The selected articles will now appear in the Upload Manager.
</Accordion>

<Accordion title="Upload Manager">
  The Upload Manager lists all articles selected via the Posts Manager, as well as articles previously published using the publish widget.

  Upload icon colours indicate the current sync status of each article:

  - **Grey** — New article that has never been published to Canvasflow.
  - **Green** — Article is successfully published and in sync with Canvasflow.
  - **Orange** — Article has been updated in WordPress but not yet re-published to Canvasflow. Click **Upload / Update** to sync the latest content.

  Additional options (Issue, Collection, or Style) appear depending on what is configured in the connected Canvasflow publication.
</Accordion>

### Step 4 — Configure the Canvasflow WordPress Connector (Server Side)

Once the plugin is connected, a new **HTML To CF Connector** menu becomes available in your Canvasflow publication settings. This provides server-side control over how WordPress content is processed by Canvasflow.

<Steps>
  <Step title="Open connector configuration">
    In your Canvasflow publication settings, click **Configure Connector** under the **HTML To CF Connector** menu.
  </Step>
  <Step title="Configure component mappings">
    The **Components** section controls how incoming HTML tags are converted into Canvasflow components. For example, you can map an `H1` tag to the **Title** component and `H2` to **Subtitle**.

    Canvasflow provides sensible defaults for common HTML tags. To customise:

    - **Add a mapping** — Click **Add**, enter the HTML tag (e.g. `H6`), select the corresponding Canvasflow component, and click **Save Changes**.
    - **Edit a mapping** — Find the component and select a new option from the dropdown, then click **Save Changes**.
    - **Delete a mapping** — Click the **Delete** (trash) icon next to the component and click **Save Changes**.
  </Step>
  <Step title="Configure content excludes (optional)">
    The **Content Excludes** section lets you prevent specific HTML elements from being imported into Canvasflow. For example, you can exclude author bios, social links, or intro paragraphs by filtering on HTML attributes.

    To add an exclude:

    1. Click **Add** in the Content Excludes section.
    2. Enter the HTML **Attribute** you want to target (typically `class` or `id`).
    3. Enter the **Attribute Value** (for example, `author`, `social`, or `intro`).
    4. Click **Save Changes**. The next time you publish from WordPress, any content matching this exclude will be omitted from the Canvasflow article.

    To remove an exclude, click the **Delete** (trash) icon next to it and click **Save Changes**.
  </Step>
</Steps>

## Troubleshooting: Problems Activating the CF-WP Plugin

If you see an error when trying to activate the Canvasflow for WordPress plugin, the most likely cause is that your MySQL database is using the **MyISAM** storage engine. The Canvasflow plugin uses referential integrity (foreign keys and relationship constraints), which MyISAM does not support. Converting the relevant tables to **InnoDB** resolves the issue.

### Check Your Storage Engine

<Steps>
  <Step title="Log in to phpMyAdmin">
    Open phpMyAdmin and navigate to your WordPress database.
  </Step>
  <Step title="Sort tables by engine type">
    Click the **Type** column header to sort tables by their storage engine. Any tables using MyISAM will be clearly visible.
  </Step>
  <Step title="Alternatively, run a SQL query">
    Run the following query to list any MyISAM tables, replacing `database` with your actual database name:

    ```sql
    SELECT TABLE_NAME, ENGINE
    FROM information_schema.TABLES
    WHERE TABLE_SCHEMA = 'database'
    AND ENGINE = 'myISAM'
    ```
  </Step>
</Steps>

### Convert MyISAM Tables to InnoDB

<Steps>
  <Step title="Back up your database">
    Always back up your MySQL database before running any conversion commands.
  </Step>
  <Step title="Run the ALTER TABLE command">
    For each table that needs converting, run the following SQL command (replace `wp_posts` with the actual table name):

    ```sql
    ALTER TABLE wp_posts ENGINE=InnoDB;
    ```
  </Step>
  <Step title="Alternatively, convert via phpMyAdmin">
    In phpMyAdmin, click on the MyISAM table, then open the **Operations** tab. Use the **Storage Engine** dropdown to select **InnoDB** and save.
  </Step>
  <Step title="Re-activate the plugin">
    Once all required tables have been converted to InnoDB, return to the WordPress admin dashboard and activate the Canvasflow for WordPress plugin.
  </Step>
</Steps>

<Warning>
  Before converting to InnoDB, ensure you are running **MySQL 5.6.4 or higher**. Earlier versions may encounter issues with unsupported full-text indexing. Always back up your database before making any changes.
</Warning>
