Issues are the organisational layer within an issue-based publication, grouping articles together into discrete editions — for example, a monthly magazine issue or a weekly newsletter edition. The **Issue Manager** is where you create and manage all issues within a publication, and every article in an issue-based publication must belong to an issue before it can be edited or published.

<Note>
  Issues are only available in **Issue Based** publications. If your publication was created as **Article Based**, articles are managed directly without issues. If you need issue-based organisation, you must create a new Issue Based publication — the publication type cannot be changed after creation.
</Note>

## What Is the Issue Manager?

When you enter an issue-based publication from the Brand Manager, the Issue Manager is the first screen you see. It lists all existing issues and provides the controls to create, edit, and delete them. Each issue acts as a container for a set of related articles that you intend to publish together as a single edition.

## Creating an Issue

<Steps>
  <Step title="Open the Issue Manager">
    Navigate into your issue-based publication from the **Brand Manager**. The Issue Manager will be displayed, listing any existing issues.
  </Step>
  <Step title="Start creating a new issue">
    Click **Create Issue**. The **Create Issue** window will appear.
  </Step>
  <Step title="Name and describe the issue">
    Enter a name for your issue (for example, "July 2025 Edition"). Optionally, add a description to help identify the issue within the Issue Manager.
  </Step>
  <Step title="Save the issue">
    Click **Create**. The issue will be created and will appear in the Issue Manager, ready for articles to be added.
  </Step>
</Steps>

## Editing an Issue

You can update an issue's name and description at any time.

<Steps>
  <Step title="Locate the issue">
    Navigate to the publication that contains the issue you want to edit. The Issue Manager will list all available issues.
  </Step>
  <Step title="Open the edit window">
    Find the issue you want to update, click the **More Options** menu on the issue card, and select **Edit**. The **Edit Issue** window will appear.
  </Step>
  <Step title="Make your changes">
    Update the name, description, or any other editable fields as required.
  </Step>
  <Step title="Save your changes">
    Click **Update** to apply the changes. The issue details will be updated immediately.
  </Step>
</Steps>

## Deleting an Issue

You can delete issues from your publication at any time. Take care before deleting — this action removes all articles within the issue.

<Steps>
  <Step title="Navigate to the Issue Manager">
    Open the issue-based publication that contains the issue you want to delete.
  </Step>
  <Step title="Select the issue to delete">
    Hover over the issue you wish to delete. From the menu that appears, click **Delete**. A confirmation prompt will be displayed.
  </Step>
  <Step title="Confirm deletion">
    Click **Delete** to permanently remove the issue and all of its articles.
  </Step>
</Steps>

<Warning>
  Deleting an issue is **permanent and cannot be reversed**. All articles within the issue will also be permanently deleted. Make sure you have exported or backed up any content you need before proceeding.
</Warning>

<Accordion title="What if I'm connected to Pugpig?">
  Deleting an issue does **not** automatically remove it from your production feed. If you are connected to the Pugpig channel and want to remove the edition from your app, you must first select **Remove Issue from Production** before deleting the issue in Canvasflow.
</Accordion>
