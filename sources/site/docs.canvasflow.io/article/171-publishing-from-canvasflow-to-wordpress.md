# Canvasflow Export to WordPress

Canvasflow provides a simple yet powerful way to export articles created in Canvasflow directly to WordPress. To setup the Canvasflow Export plug-in follow the steps below:

#### Install the plugin

1. Download and install the [Canvasflow Export Plugin](https://wordpress.org/plugins/canvasflow-export/)
2. Activate the plugin via the WordPress Admin dashboard

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5cb862500428631459c0db6a/file-pusOGezMfv.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5cb862500428631459c0db6a/file-pusOGezMfv.png)

3. Access the plugin settings.  This can be found in **Settings** >> **Canvasflow Export** [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5cb867992c7d3a18ac7ac5da/file-Nm1PeQJwyE.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5cb867992c7d3a18ac7ac5da/file-Nm1PeQJwyE.png)
4. The plugin will automatically generate the details required to connect Canvasflow to your WordPress install.  Make a note of both the **API Key** and **A****PI Path** - these will be required when setting up the WordPress channel connector in Canvasflow. 

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5cb864030428631459c0db7a/file-qiQaI3rKK0.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5cb864030428631459c0db7a/file-qiQaI3rKK0.png)

### Adding a WordPress Channel Connector

1. From your Canvasflow account, navigate to the Publication Manager
2. Select the appropriate Publication and access the settings
3. Select '_Publish Channels_', and create a new channel (using the '_+_' button)
4. Select '_WordPress'_ from the list 

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5b6983250428631d7a89b974/file-xrBtr2UTzR.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5b6983250428631d7a89b974/file-xrBtr2UTzR.png)

 Complete the required fields:

5. - Enter a channel name for the connector.  Typically this is the name of your WordPress blog but can be called anything you want 
 - Select CF Plugin for the connection type
 - Enter the API Key generated by the Canvasflow Export plug-in 
 - Enter the API Path generated by the Canvasflow Export plug-in
6. Click '_Add Channel_'.  Your publication is now connected to your WordPress blog
7. Switch to the article manager and ensure the WordPress channel is selected.  Click the publish button on any article to publish to your WordPress blog
