# Preview mode

Canvasflow offers the ability to quickly preview an article, style or template in a specific device environment.

This provides a simulation of exactly how your published article will appear without the overlaid editing tools or the need to publish.

#### To access preview mode

1. From the menu, click `Workspace`.
2. Click the 'Device Preview' button located below the 'Workspace Options'.  The canvas will change to 'Preview Mode'.
3. Use the scrollbar to scroll up and down the article.
4. If required, click an alternative workspace to preview in a different environment.
5. To exit the preview mode, click the close (`X`) button.

## Device type component visibility

_Set the visibility stats of media components on a device type basis._

By default, components that are not eligible for display on a particular device are hidden when the workspace is set to that device type.  However, it may sometimes be useful to be able to see which components will be hidden for a particular device.  Toggling the 'Device Type Component Visibility' allows you to get a better overview of how each component will be affected when changing the workspace.

### Toggling device component visibility

1. Enter preview mode via the 'Workspace' menu.
2. Toggle the `Hidden Components` button located below the 'Workspace Options'.
3. Switch between workspaces to change the device type.  As you switch, components that should not be displayed, will appear with 50% transparency rather than being hidden.
4. To hide non-eligible components, toggle the option off.  Components will now disappear when the workspace is set to the appropriate type.

### Notes:

- When in preview mode, all editing features are disabled apart from the ability to switch the current style.
- Toggling device type component visibility is **only** available when in preview mode.
