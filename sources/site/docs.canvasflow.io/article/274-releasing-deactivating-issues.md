# Releasing & Deactivating Issues

### Releasing / activating an issue

Once content is ready for publishing, the issue must be released for it to become publicly available in the PWA (Progressive Web App). 

### Step by step

1. Select the issue to be 'Article Manager' to the issue being released.
2. From the toolbar, click the `Release Issue` button. 
3. Click `Confirm` .
4. Click `Release the Issue`. The issue is now visible in the PWA.

### Deactivating an issue

To deactivate or hide an issue that is currently public:

1. Navigate via ‘Article Manager’ to the issue being deactivated.
2. From the toolbar, note the icon signifying the issue's current status.
3. Click `Deactivate` to hide the issue from public view.

4. Click `Confirm` . This will immediately remove the issue from the PWA. Notice the option icon now switches to 'Activate'.
