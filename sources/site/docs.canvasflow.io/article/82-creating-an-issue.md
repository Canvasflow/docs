# Creating an Issue

1. Navigate to the 'Issue Manager' and click `Create Issue`. The 'Create Issue' window will be displayed.
2. Give your new issue a name and a description.
3. Click `Create`. The issue will be created and will appear in the 'Issue Manager'.
