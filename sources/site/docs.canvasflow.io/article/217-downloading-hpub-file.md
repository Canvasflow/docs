# Downloading a HPub file

To download a HPub file:

1. Ensure a HPub has been [added](https://docs.canvasflow.io/article/215-adding-hpub-connector) to your brand.
2. Navigate to 'Article Manager'.
3. From the toolbar, click the `HPub` icon.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5c796a1304286350d0888965/file-EUwkF7G47H.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5c796a1304286350d0888965/file-EUwkF7G47H.png)

4. A prompt will ask if you want to build the HPub file, select `Confirm` to start the download.

### Notes

1. You can inspect the contents of a .hpub file by changing the extension to .zip and extracting it.
