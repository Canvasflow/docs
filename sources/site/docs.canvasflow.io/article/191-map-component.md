# Map Component

Maps can be used in a number of different ways within an article. One of the most obvious is to provide directions to an event. To use a map, place a 'Map Component' and enter the required postcode or copy and paste the corresponding Google Maps URL or share code.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5b6871170428631d7a89b2c0/file-BJuUTyCdqm.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5b6871170428631d7a89b2c0/file-BJuUTyCdqm.png)

#### **Zoom Level:** Adjust the strength of the map's zoom.

#### **Map Style:** Change the map's appearance with styles such as Google's default, Apple Maps, Greyscale, Subtle Blue, etc.

#### **Caption:** Add a caption, such a label for the location.

#### **Full Bleed:** Fits the component to the full width of the page, removing padding.

#### **Marker:** Set a marker to clearly define the exact location the map is being used to show.

#### **Display on Device:** The 'Display On' option allows you to choose which devices the map will appear on. The defaults are mobile, tablet and desktop.
