# Button Component

The 'Button Component' can be used to create call to actions and links to webpages or other external content.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5d6f7b0f04286364ce5917c3/file-UQq8gyUg01.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5d6f7b0f04286364ce5917c3/file-UQq8gyUg01.png)

## Creating a Button:

- Navigate to the style for which you want to create a button.
- Scroll down to the 'Buttons' section.
- Select `+ Create Button` .

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5c93bb3a0428633d2cf3e527/file-JHVugVw8Vb.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5c93bb3a0428633d2cf3e527/file-JHVugVw8Vb.png)

- Assign a name for the button.
- Select the `Paintbrush` icon or the button itself to make changes such as:
 - Size
 - Font
 - Text Size
 - Button Colour
 - Text Colour
 - Letter Spacing
 - Bottom Margin
 - Line height
 - Case
- Save and return to the article.

## Using the Button component

The Button component can be used even without any buttons saved in the style, but we recommend at least one is created to compliment your typical canvas colour and text format.

Once dragged onto the canvas, select the button to display the 'Properties Menu'. Here you'll have the options for:

- Style: This is how you apply a button style to your component, select the name of one of the buttons you've created, or `None` for the default appearance.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5cd412e304286306738eec15/file-lwZKOeKq5H.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5cd412e304286306738eec15/file-lwZKOeKq5H.png)

- **Text:** The text displayed inside the button or button label.
- **URL:** A web link, anchor link or for some platforms such as Twixl Publisher, a 'Custom URL Scheme' which links to other pieces of content within the app.
- **Open in New Window:** Determine if when selected, the link open in a new window, or simply redirects.
- **Alignment:** Aligns the button to the left, centre or right.
- **Size:** With a 'Button Style' selected, the 'Use Style' option will inherit it's properties from that style. Alternatively, select from the options Small, Medium and Large.
- **Display On:** Select from a list which devices the button should display on.
