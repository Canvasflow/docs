# Change Template Style

Canvasflow supports the ability to dynamically change the style that is currently associated with a template.

#### Changing the style of a template:

1. From within the 'Template Builder', click the `Style` button.  A list of available styles will be displayed.
2. Click the style you want to apply to the template.  The selected style will be applied.
3. Click outside of the style menu to close the menu.
4. Click `Save` to apply the style change.

#### Editing the currently selected style:

Making a change to the currently selected style is possible from within 'Template Builder'. To do this:

1. First save the template.  (Editing a current style will navigate you away from the current template).
2. Click the `Style` button from the template menu. The current style will be selected.
3. Click `Edit`.
4. You will be forwarded to the 'Style Builder' with the current style selected.
5. Make the required changes and click `Save` to apply them.
6. You can return directly to the template by clicking the `Return to Template` button.
