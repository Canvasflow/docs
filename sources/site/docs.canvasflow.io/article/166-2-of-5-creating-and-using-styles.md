# 2 of 5 - Creating and using Styles

### Styling your article

'Styles' are layers that can be applied to articles that determine the design or look and feel of an article. A style enables you to control background colour, text colour, font and sizes, padding and a number of other design decisions. Styles are independent to an article's content so they can be changed or applied to different articles at any time. 

1. From within the article builder, select the `Style` menu from the toolbar.
2. Choose the currently selected style and click `Edit`.

 [https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab139092c7d3a56d887234a/file-2IKyneorV1.png](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab139092c7d3a56d887234a/file-2IKyneorV1.png)

3. You'll be taken to the style builder, from here you can edit the canvas of the style by selecting the paintbrush icon.
4. In 'Canvas Properties' you can change the background colour and the style padding

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5e69f9a72c7d3a7e9ae90fea/file-VDnK7G9rDa.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5e69f9a72c7d3a7e9ae90fea/file-VDnK7G9rDa.png)

5. Clicking individual components will display their properties panel, allowing you to edit several options.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5e69fa2b2c7d3a7e9ae90ff3/file-dXJSdwz3Bg.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5e69fa2b2c7d3a7e9ae90ff3/file-dXJSdwz3Bg.png)

6. Properties are unique to each individual component, so changing a headline won't affect subtitle and vice versa.
7. Once changes have been made, select `Save`, and then `Back to article`.
8. Your article's style is now updated with the new changes.

### Applying a style

Existing styles can be applied to one or more articles. To do this, edit an article and select the style you wish to apply from the 'styles' menu. Try switching between styles to see how it affects the content.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5b4df9d30428631d7a89037c/file-gZrP5zJXMB.gif)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5b4df9d30428631d7a89037c/file-gZrP5zJXMB.gif)

To create new styles, you can navigate to the 'Style Manager' from the 'Article Manager' using the toolbar, here you can create extra styles or edit existing ones.

Alternatively, this video demonstrates how to work with styles.
