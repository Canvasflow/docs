# Editing an Article

1. Navigate to the article manager and find the article you wish to edit.
2. From the 'Options' column, click the 'cog' button.  An 'Edit Article' window will be displayed.
3. Edit the name and/or description of the article.
4. If required, the stye associated with the article can be changed.
5. Make the required changes and click 'Update' to apply.
