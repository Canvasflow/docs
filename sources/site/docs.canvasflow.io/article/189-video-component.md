# Video Component

A video can be embedded using a URL or via uploading a video file:

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5b6870a82c7d3a03f89d65cc/file-DoHmnmMzYq.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5b6870a82c7d3a03f89d65cc/file-DoHmnmMzYq.png)

#### Web Video / Video file

For web video, simply paste the full URL, ID, or embed code of a Youtube, Vimeo, Facebook, or Vidyard video into the box.  The 'Movie Option' allows you to upload a video file from your device.

#### Aspect Ratio

Controls the aspect ratio the video will be displayed as.

#### Poster Image

A poster image can be uploaded. This will be shown as the default frame in the article before a video is played. Please note this option is only available for uploaded videos.

#### Show Suggested Videos

Choose whether suggested videos from platforms such as Vimeo and YouTube are shown after the video playback ends.

#### Full Bleed

Fits the video to the full width of the page, removing padding.

#### Credit

Allows a credit to be added for the video's creator, shown in the bottom right.

#### Caption

Allows a text snippet to be shown underneath the video.

#### Display on Device

The 'Display On' option allows you to choose which devices the component will be displayed on. The defaults are mobile, tablet and desktop.
