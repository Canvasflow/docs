# Gallery Component

A gallery component allows multiple images to be displayed using a slide effect.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5c9361800428633d2cf3dfc0/file-OSx8DQbHwU.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5c9361800428633d2cf3dfc0/file-OSx8DQbHwU.png)

#### Speed

This dictates how fast the gallery transitions from image to image.

### Autoplay

With 'Autoplay' enabled, the gallery will begin transitioning from image to image as soon as it's viewed. When disabled, readers will have to scroll manually or use the dots beneath to advance through the images.

### Animation

- Slide: Images slide from left to right when transitioning.
- Fade: Images fade when transitioning.

### Direction

With 'Slide' selected, the 'Direction' options allows the choice between a horizontal left to right transition, or a vertical top to bottom transition.

#### Aspect Ratio

The 'Aspect Ratio' option provides a way to easily identify the aspect ratio of multiple images in a gallery.  Once images have been added and an aspect ratio selected, a warning notification will appear next to the uploaded image if the aspect ratio value doesn't match.

- Once an aspect ratio is selected, clicking the _'__Crop'_ button next to the image will display the cropping tool. The default crop size provided will be that of the selected _'_Aspect Ratio' value.

#### Caption

- Using 'Gallery Caption' will add a caption to the entire gallery. Select the slider and enter your text into the box provided.

 [https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5adda3602c7d3a0e93679811/file-Ng71Q1miKn.png](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5adda3602c7d3a0e93679811/file-Ng71Q1miKn.png)

- To add a caption to each individual image, select the 'Speech Bubble' icon next to the image in the upload list. A prompt will appear, add the caption content required and click `OK`, repeat for each slide.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5add9fe0042863075092b40d/file-9WYIeTAHAC.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5add9fe0042863075092b40d/file-9WYIeTAHAC.png)

#### Image Ordering

To change the order of the images in the slide, click and drag the image using the placement button.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5adda40b042863075092b446/file-ka2XTwJBMj.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5adda40b042863075092b446/file-ka2XTwJBMj.png)

#### Full Bleed

Fits the component to the full width of the page, removing padding.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5c9361e90428633d2cf3dfc4/file-NdM9wdAefu.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5c9361e90428633d2cf3dfc4/file-NdM9wdAefu.png)

#### Display On Device

The 'Display On' option allows you to choose which type of devices the gallery will be displayed on. The defaults are mobile, tablet and desktop.
