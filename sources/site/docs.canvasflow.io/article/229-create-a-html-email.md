# Create a HTML email

### Overview

As well as outputting to the multiple publishing channels Canvasflow supports, it's also possible to generate a fully responsive HTML email from any article.

### Step-by-step

1. Select which brand you require and navigate to 'Article Manager'.
2. Click the `Settings` icon (cog) of the article from which to create a HTML email.
3. Select `Download`.
4. From the flyout select `HTML Email` and confirm your choice in the popup.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5cb5c9520428631d263c2e30/file-hVqXS4jeQY.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5cb5c9520428631d263c2e30/file-hVqXS4jeQY.png)

5. A browser window will display the article's content as a HTML document
6. You can now download your HTML email using one of the following methods dependent on your browser.
 1. For Chrome and FireFox, right click the page, select 'View Page Source' or 'Page Source', press CTRL+A to highlight the entire page, and CTRL+C to copy the contents.
 2. For Safari, use the keyboard shortcut to view page source `Option+Command+U`, then `CTRL+A` to highlight the entire page, and `CTRL+C` to copy the contents to your clipboard.
7. Using CTRL+V or the right click menu, paste the HTML content into your email distribution platform.

### Notes

1. You can use a tool such as [Putsmail](https://putsmail.com/tests/new) to test your email displays and functions as intended before sending.
