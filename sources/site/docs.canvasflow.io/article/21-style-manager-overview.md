# Style Manager Overview

The 'Style Manager' is where you can create and manage styles that exist within your publication. The style manager can be accessed via the secondary toolbar from within any publication, or from the 'Style menu' in the 'Article Manager'.

Styles are separate to the content and structure of your articles and are designed to be reused. Once a style has been created, it can be applied to articles or templates at any time.

### **Style manager options**

The style manager allows you to perform the following actions:

- [Create a new style](https://docs.canvasflow.io/article/19-creating-a-new-style)
- [Customise a style.](https://docs.canvasflow.io/article/53-building-a-style)
- [Edit the name and description of a style.](https://docs.canvasflow.io/article/75-editing-a-style)
- [Delete a style.](https://docs.canvasflow.io/article/76-deleting-a-style)
