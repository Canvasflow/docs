# Image Component

Selecting an image component displays the image properties tab, the following properties are editable: 

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603fc3940a2dae5b58fb589b/file-zfR7cyGqsf.png)

- **Add/Edit Image**: Upload or change an image and insert it into the image component.
- **Crop**: Using the crop icon on the image thumbnail, access the cropping feature.
- **Link**: Both Web URL and Page Links are possible, but the [Page Link](https://docs.canvasflow.io/article/276-adding-page-links) feature is only possible with some connections, such as PWA and Paperlit.
- **Open in New Window**: If a link is attached to the image, choose whether selecting the image will open the link in a new window, or simply redirect.
- **Caption**: Add a caption to an image.
- **Credit:** Credit the image, such as the photographer or source.
- **Filter**: Choose from a list of Instragram filters to enhance your image. Learn more about filters [here](https://docs.canvasflow.io/article/216-image-filters).
- **Full Bleed**: Fits the image to the full width of the page, removing padding.
- **Use RAW**: Images uploaded to Canvasflow (over 2048px) are automatically optimised. Enabling the 'RAW' image feature forces Canvasflow to use the original, un-optimised file.
- **Expand Full Width**: Expand an image to it's full width.
- **Force Full Width**: Enlarge an image to ensure it fits the entire width of the device, even if the original image size is smaller than that of the screen width. If the image is significantly smaller than the maximum width of the article, some pixelation may occur.
- **Make Unselectable**: Change whether the image is selectable in the final article. This is only applicable when connected to a Pugpig Publish channel.
- **Fixed Width**: Resize an image based upon width. Please note that when setting a fixed width larger than the raw image size, some pixelation may occur.
- **Display On Device**: The 'Display On' option allows you to choose which devices the component will be displayed on. The defaults are mobile, tablet and desktop.
- **Tag:** Tag an image with keywords.
