# 1 of 5 - Creating an article

### Creating an article

The 'Article Manager' is where all your articles can be found, it's the hub of your publication. 

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5ab1113c2c7d3a56d8872187/file-ir7JcdVYKT.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab1113c2c7d3a56d8872187/file-ir7JcdVYKT.png)

1. Select the `+` icon, or `Create Your First Article` button to get started.
2. The fields available are:
 1. Name.
 2. Description.
 3. Template - Later on you'll be able to create templates for quick article creation, but for now choose `none` .
 4. Style - The style that will be associated to the article.  You'll learn more about styles shortly, but for now select any style you like.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5ab11348042863478ea7b275/file-Fl5sOSG5RV.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab11348042863478ea7b275/file-Fl5sOSG5RV.png)

 [https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab11348042863478ea7b275/file-Fl5sOSG5RV.png](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab11348042863478ea7b275/file-Fl5sOSG5RV.png)

3. Once you complete the required fields, click `Create`.
4. The new article will be displayed in the 'Article Manager'.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5ab113bf042863478ea7b27e/file-hGLW8Ff23X.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab113bf042863478ea7b27e/file-hGLW8Ff23X.png)

 [https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab113bf042863478ea7b27e/file-hGLW8Ff23X.png](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab113bf042863478ea7b27e/file-hGLW8Ff23X.png)

5. When connected to a publishing platform, each piece of content will display it's publish-state (.e.g. unpublished, published, published but not up to date). Articles are specific to the publication they're originally created in.

### Adding content to an article

Canvasflow provides an intuitive content authoring tool allowing publishers to create responsive HTML5 content without the need for developers.

To populate your article with content:

1. Select your newly created article, you'll be taken to the 'Article Builder'.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5ab12be52c7d3a56d88722a5/file-KHyfw1EtUA.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab12be52c7d3a56d88722a5/file-KHyfw1EtUA.png)

 [https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab12be52c7d3a56d88722a5/file-KHyfw1EtUA.png](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab12be52c7d3a56d88722a5/file-KHyfw1EtUA.png)

 [https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab12be52c7d3a56d88722a5/file-KHyfw1EtUA.png](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab12be52c7d3a56d88722a5/file-KHyfw1EtUA.png)

2. On the left you'll find a list of components, from text components such as headline and paragraph, to rich media such as images and video.
3. Choose a text component such as headline, title or subtitle, then drag and drop onto the canvas.  Each component will display an indicator when dragged, showing where it can be dropped, useful for when dropping new content between other components already on the canvas.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5b4ddde12c7d3a03f89cad30/file-iK1f82qyR0.gif)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5b4ddde12c7d3a03f89cad30/file-iK1f82qyR0.gif)

 [https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5b4ddde12c7d3a03f89cad30/file-iK1f82qyR0.gif](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5b4ddde12c7d3a03f89cad30/file-iK1f82qyR0.gif)

4. Click the text component you just placed on the canvas to start editing content.
5. Next, select an image component and drag it onto the canvas.
6. Select the image component by clicking anywhere on the image.
7. The 'image properties panel' will be displayed. Amongst other options, this will allow you to change the image, add captions, as well as formatting it to stretch to the edges of the canvas if required. [https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab132342c7d3a56d88722e8/file-yxQwU7ZGql.png](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab132342c7d3a56d88722e8/file-yxQwU7ZGql.png)

### Re-order, remove and resize

Content can be reordered or removed using the 'inline component controls' to the left of each component when hovered over, while more complex layouts can be created using multiple columns. All content is 100% responsive so it looks great across all devices - use the 'workspace manager menu' to set the appropriate canvas size.
