# Inline Images

Canvasflow's support for inline images means you can add images to content without using the standard 'Image Component'. Instead you can embed an image into a block of text at will.

#### To add an Inline Image:

1. From the _'_Article Builder', highlight a space in a text component.
2. In the 'Text Formatting Bar' which appears, select the `Image` icon.

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5e186ae02c7d3a7e9ae60793/file-tfJRK5MZbG.png)

3. In the popup, choose either a local image file, or enter an image URL, and select `Insert Image`.

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5e186b402c7d3a7e9ae60799/file-xy3pNOqwRA.png)

4. With the inline image now added, you can resize it by dragging one of the corners. To delete the image, simply select in front of it and press `Backspace`.
