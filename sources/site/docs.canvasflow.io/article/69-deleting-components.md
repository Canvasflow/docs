# Deleting Components

All placed components can be easily removed from an article or template using the 'Delete Component' option. 

### To delete a component:

1. Hover over the component that you wish to delete.  The component toolbar will be displayed to the left of the component. 
2. Click the '`Trash`' icon. A confirmation popup will be displayed.

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5a942353042863534055934d/file-AeA3NaixLm.png)

3. Click `Delete`.  The component will be deleted.
4. Save the article to commit the change.

### Notes:

1. Once the article has been saved, deleting a component becomes **permanent**.
2. If you delete a component by mistake and have not yet saved the article or template, you can recover the deleted component by refreshing the browser. This will return you to the point at which you last saved the article.
3. Deleting a column component which has a style block applied **does not** delete the actual style block, it is only removed from the current article or template.
