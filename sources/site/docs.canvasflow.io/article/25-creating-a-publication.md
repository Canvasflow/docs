# Creating a Publication

1. Navigate to the Brand Manager and click `Add Publication`.  The 'Create Publication' window will be displayed.
2. Select the required publication type (see below for publication types).

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5e7cd33004286364bc9751f6/file-WFIfDJi28N.png)

3. Give your publication a name and (optionally) a description.
4. Click `Create`. Your new publication will be created. 

### Publication Types

Canvasflow offers the ability to create either an Article or Issue based publication.  

1. **Article Based** Article based publications support the continuous publishing model, allowing articles to be managed and published individually and without the need for them to be organised by issue.
2. **Issue Based** Issue based publications support the more traditional print-based issue model, allowing articles to be managed and organised by issue.

### Notes:

1. A publication name and description information are for internal use only and can be changed at any time.
2. A publication type **cannot** be changed once it has been created.
