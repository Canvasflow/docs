# Full Page Advert Component

The Full Page Advert component allows the insertion of a full-page advert.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5b6873390428631d7a89b2cf/file-Rs99t3AD0Q.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5b6873390428631d7a89b2cf/file-Rs99t3AD0Q.png)

#### Fit

- **Fit Height -** (letterboxing / no scrolling): Fit the device height at all times.
- **Fit Width** - (Scroll): Scales image to fit device width and create a scrollable page.

#### Full Bleed

Fits the component to the full width of the page, removing padding.

#### Use RAW

Images uploaded to Canvasflow are automatically optimised, selecting to use the RAW image makes use of the original un-optimised file.

#### Make Unselectable

Change whether the image is selectable in the final article. (Only applicable when connected to a Pugpig Publish channel).
