# Creating an Apple News Channel

To begin publishing to Apple News, an Apple News channel will first have to be created.

**To create a channel:**

1. Set up an iCloud account if you don't already have one: [https://www.icloud.com/](https://www.icloud.com/)
2. Navigate to the Apple News Publisher: [https://www.icloud.com/#newspublisher](https://www.icloud.com/#newspublisher)
3. Follow the prompts until you're able to add publisher and channel information such as Website URL, and Audience (General, Mature or Children)

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5e25765804286364bc941b41/file-2Etnf4YyFg.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5e25765804286364bc941b41/file-2Etnf4YyFg.png)

4. Add a logo and channel icon - [Apples Logo Guidelines](https://support.apple.com/en-gb/guide/news-publisher/apd7c9ae979c/icloud) state it must be a PNG, less than 2MB, text only, and match the name of the publication
5. Select Next
6. Fill out the page with any necessary contact information
7. Selecting Next again will create your channel
