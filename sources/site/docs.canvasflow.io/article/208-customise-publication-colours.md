# Customise Publication Colours

To allow adherence to your brand stylesheet, you can customise the colour palette used for text formatting. 

### To add / edit colour(s):

1. Navigate to 'Brand Manager'.
2. Hover over the brand you wish to assign colours to.
3. Select the `Settings` icon.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5bdaf30b04286356f0a551dc/file-3LRkHYF4PD.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5bdaf30b04286356f0a551dc/file-3LRkHYF4PD.png)

4. Select the `Colours` menu tab.
5. Select one of the colour swatches and using the 'HEX Colour' box beneath, enter the HEX value of the colour you wish to add.
6. Click `Update` _._
7. Your newly added colour can now be found in the text formatting menu of 'Article Editor'.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5bdaf6a404286356f0a55208/file-kVSU1OTeJy.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5bdaf6a404286356f0a55208/file-kVSU1OTeJy.png)

### Finding HEX value of colours:

Any design program such as Photoshop or InDesign will provide a HEX value for colours upon selecting them with the appropriate tool. Alternatively you can use [HTMLColorCodes Colour Picker](https://htmlcolorcodes.com/color-picker/).
