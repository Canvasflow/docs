# Creating a New Style

Canvasflow provides the ability to create an unlimited number of styles.  Each style can be individually customised and linked to one or more articles.

## Creating a new style

1. From the dashboard, select the publication you wish to work on.
2. From the style manager menu, click the 'Create style' button at the top right. 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603fad40661b720174a72ecf/file-6DCqWIbGQ7.png)

3. Give your style a name and a description.
4. Select the 'Scope' of Style you wish to create, either 'Publication' or 'Global' (Read more on Style Types [here](https://docs.canvasflow.io/article/244-publication-and-global-styles))
5. Select the 'Type' of Style you wish to create, either Article, [Inline](https://docs.canvasflow.io/article/294-inline-styles) or [Device](https://docs.canvasflow.io/article/293-device-styles). (Article is the standard Style type)
6. If you wish to create the style from an existing style, select 'Copy From' from the 'Source' list, or 'Inherit From' to create an [Inherited Style](https://docs.canvasflow.io/article/292-inherited-styles). Otherwise select 'New'
7. Click 'Create'.  Your new style will be created and will appear in the style manager list
