# Editing a Template

1. Navigate to the template manager and find the template you wish to edit.
2. From the 'Options' column, click the 'cog' button.  An 'Edit template' window will be displayed.
3. Edit the name and/or description of the template.  
4. If required, the stye associated with the template can also be changed.
5. Click 'Update' to apply changes.

Notes:

- Changing the style associated with an existing template **has no effect** on articles already created using the template.
