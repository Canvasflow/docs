# Custom Style Blocks

A custom style block enables different styles to be applied to content within a single article. 

For example, the default style applied to an article may have a white background and black text using Verdana as the paragraph font style.  By using a style block, it allows these rules to be overridden for particular sections of the article. This is useful when trying to highlight or bring attention to important content.

## Working with Style Blocks

Custom Style Blocks offer the same styling options as the default text components, with the addition of being able to use background images.  Each custom style block is style specific and there is no limit to the number of blocks that can be created or applied.

### Creating a Custom Style Block

1. From the Style manager, select the style you want to create a custom style block
2. Scroll to the 'Custom Blocks' section at the bottom of the style builder and select '_+Create Block_'  

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5a93f2be2c7d3a54cdfccb04/file-jzrGP0Xfj4.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5a93f2be2c7d3a54cdfccb04/file-jzrGP0Xfj4.png)

3. This will create a new style block which inherit all the style properties applied to the default text components
4. Select the text components you want to customise (e.g. Font, Colour, Size etc)
5. To change background properties and padding, click the '_paintbrush'_ button.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5c9b509d2c7d3a154461668b/file-8tqjc8hIP1.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5c9b509d2c7d3a154461668b/file-8tqjc8hIP1.png)

6. Once finished, click 'Save' to update the style.

### Editing a Custom Style Block

To make changes to an existing style block click the text component you wish to change and apply the changes.

Alternatively, to change the padding, background colour/image, position, or even apply custom CSS, select the paintbrush icon again to access the Custom Style Block properties.

### Rename / duplicate / delete Custom Style Block

Click the 'More Options' button to rename, duplicate or delete a custom style block.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5c9510f00428633d2cf3f2c3/file-Gi1Z1jwppd.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5c9510f00428633d2cf3f2c3/file-Gi1Z1jwppd.png)

### Applying a Custom Style Block

Style blocks can be applied to article content via columns.

1. Access the article to which you want to apply a style block
2. Select '_Layouts_' in the article builder menu and drag any column onto the article
3. Hover the column and click the '_paintbrush'_ button to display the column properties panel
4. From the drop down menu, select the name of the _custom style block_ you want to apply 

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5a93fb900428635340559122/file-6P2TfSTJCW.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5a93fb900428635340559122/file-6P2TfSTJCW.png)
5. The style block has now been applied. Any text components you add into this block will inherit the styling.
6. Save the article to commit the change.

### Using the Custom Style Block as a Hero Image

Using the Background Image property of a Custom Style Block it's possible to use it as a hero image. Simple apply a custom style block to a layout component, then add text components which will sit in front of the image.

### Notes:

1. Padding applied to style blocks is **in addition** to the existing canvas padding.
2. By default, Font style, size and bold/italics of the style you're working with will be inherited by the Custom Block text components.  This can be overridden at anytime.
3. There is no limit to the number of times a Style Blocks can be used.
