# Moving Components

Once a component has been placed on the canvas, it's possible to reorder or move its position. 

### Reorder an existing component:

1. Hover over the component that you wish to move.  The component toolbar will be displayed on the left.
2. Click the 'up' to move the component up, click the '_down_' to move the component down. 

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5ab3ccdc042863478ea7cbd6/file-o8ryEh6Lbz.gif)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab3ccdc042863478ea7cbd6/file-o8ryEh6Lbz.gif)
3. Repeat until the component is in the desired location.

### Move an existing component:

Alternatively, components can be moved by dragging the existing component.  To do this:

1. At the top right of each component there is a drag button.
2. Click and drag the button to move the component to the desired location.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5ab3ce4d2c7d3a56d8873919/file-jVfNTvpako.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab3ce4d2c7d3a56d8873919/file-jVfNTvpako.png)

### Swap an existing component

Canvasflow allows components position to be directly swapped, regardless of where they are on the page or what kind of components they are. To do so:

1. Click and drag the using the '_Move_' icon on the component you'd like to swap, (shown in the screenshot above).
2. Drop the component onto the component you'd like to swap it with. 

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5ab52e7f042863794fbe8d64/file-FDT4FngAob.gif)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5ab52e7f042863794fbe8d64/file-FDT4FngAob.gif)

3. The components will swap position on the canvas, including their contents (copy/images/video).

It's also possible to freely  [change the component type](ttps://docs.canvasflow.io/article/89-changing-existing-text-component-type) of a component already on the canvas, while keeping it's content. It may be that a '_Heading_' component needs to be changed to a '_Subtitle_'. This removes the need to cut and paste content in order to change the component type
