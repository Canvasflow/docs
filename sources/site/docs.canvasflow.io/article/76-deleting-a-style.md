# Deleting a style

Styles can be deleted from your publication at any time.

### Deleting a style

1. Navigate to the _Style Manager_ and locate the style you wish to delete.
2. Select the cog icon to expose the available options

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5d721e8704286364bc8ece58/file-3Bg6jDduSX.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5d721e8704286364bc8ece58/file-3Bg6jDduSX.png)

3. Select 'Delete' - A confirmation window will pop up, select Delete again

### Deleting an 'in-use' style

It's not possible to delete a style which is currently in use, either by an article or template.  If you attempt to delete an in use style, a warning notification will be displayed.

This notification will list all articles (and templates) that are currently using the style attempting to be deleted.  To delete a style that is currently in use, you must first update all articles and / or templates listed, to use a different style.

### Notes:

- Deleting an style is **permanent** and **cannot be reversed.**
- Deleting a style has no effect on content that has already been published.  To change the style of published articles, you must update the style and republish the article for the style change to take effect.
