# Custom Text Components

Text Components can be renamed for easier identification when creating content and Custom Text Components can be added to each publication. This allows you to have, for instance, multiple styled Headline components for different use-cases:

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5c6edafa042863543ccd494d/file-A58mpcSt0O.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5c6edafa042863543ccd494d/file-A58mpcSt0O.png)

To rename Text Components or add Custom Text Components to a publication:

1. Navigate to the Publication Manager
2. Enter the settings of your chosen publication using the cog displayed at the top right
3. Select 'Text Names'
4. All text components will be listed here, with the ability to rename each, as well as turn on new components or turn off existing ones using the checkmark box:

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5c6edb792c7d3a66e32ec1a1/file-iYDX6yENzP.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5c6edb792c7d3a66e32ec1a1/file-iYDX6yENzP.png)

Once a new Custom Text Component has been turned on in a publication, you can then style that component through the editor just like the others.
