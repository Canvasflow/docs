# Building a Style

'Styles' are used to control how components and the canvas appear. 

'Style 1' for example, might have a dark blue canvas with 'Title' and 'Subtitle' components set to white and the 'Paragraph' set to light grey.

Once a style is created it can be reused or applied to multiple articles or templates, helping to ensure your content remains consistent and follows brand guidelines across your entire brand.

'Style Manager' can be accessed via the secondary toolbar from within a brand. A complete help article on 'Style Manager' can be found [here](https://docs.canvasflow.io/article/21-style-manager-overview).

When creating an article or a template you'll be asked to specify a style (this can be changed later), so once a style has been set up it can be used repeatedly. From within an article or template, you can freely change which style is attached to it, as well as edit a chosen style, using the style option in the toolbar.

### Building a style

1. Create a new style from 'Style Manager' using the `+` icon.
2. Click the style to edit to access 'Style Builder'.
3. To edit the style's canvas (padding and background colour) select the `Edit` icon on the text block.
4. To edit text components, clicking on them will display the available properties on the left menu bar.
5. To edit an image component click on the image itself.
6. To edit an image's credits, click on the line beneath it.

All components within an article will inherit the chosen style's properties. To include sections which differ from the applied style, see '[Custom Style Blocks](https://docs.canvasflow.io/article/99-custom-style-blocks)'.
