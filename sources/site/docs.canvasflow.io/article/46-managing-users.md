# Managing Users

Users are members of your company or team who have access to your Canvasflow account. This article talks about managing User accounts in Canvasflow.

## User management

In Canvasfow, users are managed on a per publication basis and provide the ability for multiple people to work on a publication simultaneously.

To find the User Management dashboard:

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5a9fc9af2c7d3a75495169ae/file-u63NTkBmKm.png)

1. From the Publication Manager, select the 'more' option represented as a cog icon on your chosen publication.  (Publication settings menu can also be accessed via the 'Settings' button from the admin toolbar once inside a publication.
2. The Publication Settings page will be displayed, select the 'Users' tab.

### Creating a new user

1. Create a new user by clicking the + icon.
2. Fill out the user information - Name, Email Address, Password and Role ([more information on user roles](https://docs.canvasflow.io/article/159-roles-permissions)).
3. Click 'Create', the User has now been created and is able to log in.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5a9fca9f04286374f708a45a/file-iOV4EKuSQG.png)

### Assigning an existing user to a publication

Existing account users can be assigned to multiple publications, eliminating the need to create multiple user accounts per publication.

### Assigning a user:

1. Select 'Create User' represented by the + icon.
2. From the tab select 'Add Existing'.![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5a9fc83d2c7d3a75495169a0/file-BJjTxoTe7D.png)
3. Select the User you would like to add from the drop down menu.
4. The User will have access to the new publication from next login.

### Note:

1. If a user is assigned to multiple publications, they will have the same user privileges across all publications.  It is not currently possible for the same user to have different privileges dependent on the publication being accessed.    

### Removing a user from a publication 

If you need to revoke access for a user for one or more publications, you can do this by simply removing a user.  Users can be removed from one or more publication at anytime.

### To remove a user

1. Access the setting of the publication you want to remove the user from.
2. From the Users tab, find the User you want to remove and click the 'more' icon.
3. Select 'Remove User' from the drop down menu.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5a9fcd0404286374f708a472/file-oVf5Gwo9NS.png)

### Note:

1. Removing a user **does not delete** the user, it simply removes access to the specific publication.  A user that has been removed from all publications in an account is still able to login. 

### Editing a user

1. From the Users tab, find the User you want to edit and click the 'more' icon
2. Select Edit from the drop down menu
3. The Edit User dashboard will be displayed, where you can edit Name, Email and Role

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5a9fd6a704286374f708a4bd/file-5eiooEIBzc.png)

### Deleting a user

A user cannot be deleted via the users tab. To delete a user, use the 'Manage Users' tab, which is accessible only to users assigned the 'Master' role.
