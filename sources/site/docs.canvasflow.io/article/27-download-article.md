# Downloading an Article

In addition to publishing directly to online platforms, you can also use Canvasflow to download articles for archival purposes or perhaps for use in traditional print based publishing.

In this process, a Zip file containing all the article's necessary assets is compiled.  Once downloaded, this file can be extracted to access the individual text and image components.

### Downloading an article:

1. Navigate to the brand which contains the required article.
2. Locate the article, then from the 'Options' menu select the `Options` icon.
3. From the dropdown, select `Download`. A success prompt will appear once the download has completed.
