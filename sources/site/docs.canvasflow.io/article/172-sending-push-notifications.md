# Sending Twixl Push Notifications

Canvasflow supports Twixl Push Notifications, enabling them to be sent to app users directly from the Canvasflow platform.

### To send a push notification:

1. Open 'Brand Manager'.
2. Hover over the Twixl connected publication required, click the `Push Notification` button displayed.

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5ab39806042863478ea7c857/file-Mxaqfz65Su.png)

3. From the popup window, enter the message you wish to send and click `Send`.

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5ab398e12c7d3a56d88735c5/file-Y6Xw59zIcV.png)

4. The message will be sent to all app users with push notifications enabled.
5. Click `X` to close the popup.
