# Editing Article Metadata

Metadata is information that describes specific aspects of an article such as the creation date, modified date and social sharing text.

## Channel specific metadata

Canvasflow presents only 'channel specific metadata'.  Only metadata that is relevant to the currently selected publishing channel is shown, helping ensure that only relevant meta information is requested. 

### Adding Twixl metadata

1. From the edit toolbar within the article manager, click the 'Metadata' button. The metadata panel will be displayed. 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5a8ea94b04286305fbc9bfa6/file-QPwhG6CZ2W.png)

2. The metadata window will be displayed 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5a8eb2022c7d3a0806494564/file-4wsv7719We.png)

3. Add the required meta information and click OK to apply the changes.
4. All changes to meta data will automatically be synced with the Twixl distribution platform, there is no need to publish the article.

### Adding metadata for Pugpig and Purple DS channels

1. From the edit toolbar within the article manager, select 'Edit'
2. All available metadata options will be displayed, such as Description and Category

### Notes:

- Metadata options are **not displayed** for articles when a publication is not connected to a publishing channel.
