# 3 of 5 - Creating and using Templates

Templates are used to save content layouts, so columns, text and rich media components all have their set places, and once a template is selected, all you have to do is add the content.

The 'template builder' works exactly the same as the 'article builder'. From inside a publication, click the `templates menu` to access the 'template manager'.

### Creating a new template

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5b4dfb6f0428631d7a890397/file-Fg4b2IYIxv.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5b4dfb6f0428631d7a890397/file-Fg4b2IYIxv.png)

1. Once a template has been created, click `edit` to load the 'template editor'. 
2. As with building an article, drag and drop the desired components onto the canvas, making any edits as required.
3. When the template is complete, select `Save` from the toolbar.
4. This template will now be shown as an option the next time an [article is created](https://docs.canvasflow.io/article/73-creating-an-article).

### Template Tip

Templates are designed to help save time and ensure consistency. Using Canvasflow it's possible to  [create a template from an existing article](https://docs.canvasflow.io/article/185-create-a-template-from-an-article). To do this, select the `Edit` icon next to an article and select `Create Template` .

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5b20dce42c7d3a0fa9a2ecf6/file-T3TI9XnodZ.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5b20dce42c7d3a0fa9a2ecf6/file-T3TI9XnodZ.png)

### Note:

1. Styles are **separate** to templates. Styles are used to set fonts, colours and padding. Templates encompass only the basic component structure and initial content for an article.
