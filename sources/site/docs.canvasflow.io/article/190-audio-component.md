# Audio Component

Audio components currently support Soundcloud and PodBean. To add an audio embed, simply copy and paste the appropriate URL or embed code into the 'Embed Field' then click `Apply`.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5b686f632c7d3a03f89d65c1/file-KludZupgaF.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5b686f632c7d3a03f89d65c1/file-KludZupgaF.png)

#### **Caption:** Add a caption to bottom of the audio clip.

#### **Full Bleed:** Let the component ignore padding and stretch the entire width of the canvas.

#### **Display on Device:** The 'Display On' option allows you to choose which devices the component will be displayed on. The defaults are mobile, tablet and desktop.
