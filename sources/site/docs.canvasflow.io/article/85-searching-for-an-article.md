# Searching for an Article

When working with a large number of articles, it can be far faster to find the required article by using the search feature. Results will appear as soon as you begin typing and will become more specific as more text is entered. The total number of results returned will appear next to the search box.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5a9026d6042863534055813f/file-A1PyHli0uo.png)

#### Searching for an article

1. Navigate to the 'Article Manager'.
2. Ensure you are using the 'Default' channel view.
3. Begin typing the name of the article you wish to find into the search box.  
4. To reset and show all articles again, delete the text from the search box.

### Notes

1. Currently you can perform a search on either the '**Title**' or '**Author**' columns.
