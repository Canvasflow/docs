# Applying a Twixl Cell Style

### Applying a cell style:

Once a brand is connected to Twixl, users are able to apply 'Cell Styles' when creating an article, collection, or content item. This can be changed later by using the 'Edit' menu.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5afaf525042863158411c9f1/file-p3P0ySSFOn.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5afaf525042863158411c9f1/file-p3P0ySSFOn.png)

More information on 'Twixl Cell Styles' can be found [here](https://help.twixlmedia.com/hc/en-us/articles/115000718205-Working-with-cell-styles).
