# Connecting to Zinio

### To Connect to Zinio:

1. Navigate to ‘Brand Manager’.
2. Hover over the brand you require and click the `Settings` button to access ‘Brand Settings’.  

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f5eb00a2dae5b58fb5507/file-aK2i4DOoKX.png)

3. Select the `Publish Channels` tab.
4. Select the `Add New` icon.
5. Enter a 'Channel Name' and select `Zinio` in the ‘Channel Selector’ dropdown.
6. Select `Add Channel`.
