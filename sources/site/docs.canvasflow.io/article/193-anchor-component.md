# Anchor Component

Anchors can be used to enable quick jumps to specific points of an article.  An example of anchor usage would be a 'back to top' anchor placed at the bottom of a page to prevent users having to manually scroll back through large amounts of previously viewed content.

#### To create an anchor linking to content on the same page:

1. From the 'Media' list, drag an 'Anchor Component' to the point in the content readers will be jumping **to**.
2. Select the 'Anchor Component' and create a unique ID.

**Notes**

1. ID's must begin with a character (A-Z), such as '#MyAnchor'

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5b69efb02c7d3a03f89d71c2/file-r3HkI9HOCV.jpg)

1. To create the link that readers will select to jump to the anchor, highlight a portion of text to expose the text formatting toolbar
2. Add a hyperlink using the 'Hyperlink' icon, and enter your anchor ID: **#MyAnchor**

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5adf51f204286328a414828f/file-EU2uJFKz5W.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5adf51f204286328a414828f/file-EU2uJFKz5W.png)

#### To link to an Anchor located in a different article:

1. Add a hyperlink to the text you want users to jump **from**.
2. Instead of entering the anchor ID, enter the URL of the article readers will be jumping to, followed by the anchor ID. For example, "https://DomainURL/13754/article.html#MyAnchor"

Notes

1. If using multiple anchors on the same page, they **must** have **unique** ID's.
