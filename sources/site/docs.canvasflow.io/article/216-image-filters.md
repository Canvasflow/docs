# Image filters

With Canvasflow it is possible to apply Instagram-like filters directly to your images without the need to edit the image directly.  Filters range from simple grayscale to more complex blend modes.

#### Apply a filter to an image

1. Select an image you want to apply a filter to.
2. From the image properties panel, select the `Filter` menu.
3. Select the filter you wish to apply.  The filter will be applied to the selected image.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5c9278080428633d2cf3d792/file-g7RzwExhil.png)

As these filters are being applied _onto_ the image, it's possible to change the effect at anytime, or remove it by setting the filter style to `'None (Default)'`.
