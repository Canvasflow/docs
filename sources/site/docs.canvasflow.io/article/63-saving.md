# Saving Changes

To save changes to an article, click the `Save` button at the top right of the article or 'Template Builder Menu'.  A message will be momentarily displayed on screen to confirm that the save has completed successfully.

### Notes:

1. If any changes are made to a style, you must save to permanently apply the changes.
2. If the option to publish from the 'Article Builder' is supported by your publish channel, publishing an article will automatically save it as well.
3. Regularly saving your work is strongly recommended.
