# Updating a PWA

Once a PWA is built, the app properties can be changed at anytime and are instantly visible to users. 

### Updating a PWA’s configuration:

1. Navigate to ‘Brand Settings’.
2. Select `Publish Channels`.
3. Click `Edit` next to the PWA channel.
4. Amend the fields as required.
5. Click `Edit Channel` to update the app. The build process takes two to three minutes to complete.

### Notes

When editing a PWA, all properties can be changed apart from the following:

- Domain
- AWS S3 Region

Please contact our support team if you require changes to these properties.
