# Working with Custom Fonts

_Once custom or web fonts are added to your publication by our support team, they need to be enabled and applied to an active style._

### Enabling custom fonts

To select which fonts are available to use:

1. From the 'Brand Manager', hover over the publication you wish to work on and click `Settings`. 
2. ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f5eb00a2dae5b58fb5507/file-aK2i4DOoKX.png)

3. From the menu select the `Fonts` tab.
4. Select the fonts you wish to use, keeping in mind that the number of active fonts can impact performance.

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5ab39baa042863478ea7c86d/file-yXDPTRWiqq.png)

5. Click `Save` to enable the selected fonts.

### Adding custom fonts to a style

To begin using your new fonts once activated in the publication:

1. Navigate to the 'Styles Menu' from the 'Article Manager Toolbar' (alternatively use the 'Style Menu' from within 'Article Builder').
2. Select `Edit` on your chosen style.
3. Select a 'Text Component', this will display the component properties.
4. From properties, select the `Font` menu and select your custom font.  All custom fonts will be located at the bottom of the fonts menu. This is also where you can add [Font Style Variants](https://docs.canvasflow.io/article/291-font-style-variants).
5. Save the style. 

### Notes

1. Custom fonts are managed on a per publication basis and there is no limit to the number of fonts your publication can have installed.
2. To ensure your publication remains optimised, we strongly suggest that you enable **only** the custom fonts that are actively being used.
3. If a custom font is enabled, all articles using the parent style will include that font.
