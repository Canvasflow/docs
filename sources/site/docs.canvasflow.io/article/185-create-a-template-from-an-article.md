# Create a template from an article

Canvasflow enables you to save time by creating templates from existing articles to re-use in future content. Here's how.

1. Navigate to your chosen publication.
2. Hover over the article you'd like to create a template from and select the `Edit` menu.
3. Select 'Create Template'

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5b20dce42c7d3a0fa9a2ecf6/file-T3TI9XnodZ.png)

4. The new template can now be found in the 'Template Manager' using the same name as the article used to generate it.
