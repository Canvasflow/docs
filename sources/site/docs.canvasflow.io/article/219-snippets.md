# Creating a Snippet

Snippets are very similar to templates but with the added advantage of being useable in existing articles.

Snippets offer the ability to create combinations of content which can be reused multiple times, removing the need to recreate individual components for different articles. 

#### Creating a Snippet

Creating a snippet is done in the same way as creating a template. The 'Type' dropdown allows you to to choose between them:

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5cdd3ae82c7d3a6d82bd88fc/file-sVN6IWfUGE.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5cdd3ae82c7d3a6d82bd88fc/file-sVN6IWfUGE.png)

- **Snippet**: Can only be used as a snippet, cannot be used to create articles. Will appear in the snippets tab of the 'Article Builder'.
- **Template:** Can only be used as a template to create articles. Will not appear in the snippets tab of the 'Article Builder'.

The main reason for differentiating between a Snippet and a Template is to keep the snippets tab in the 'Article Builder' organised. This is especially useful if you have a large number of templates that you don't want to be visible as snippets. Here's a full of explanation of [How to Create a Template](https://docs.canvasflow.io/article/17-creating-a-new-template), and H[ow to Build a Template](https://docs.canvasflow.io/article/55-building-a-template), which is also applicable to Snippets.

#### **Using Snippets**

Inside 'Article Components', the 'Snippets' tab, lists all snippets currently available to the publication.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5c93a8912c7d3a1544612c14/file-mpuVwdUAba.png)

Dragging a snippet onto the canvas will place the template's entire content onto the canvas which then inherits the article's style.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5ca7825c2c7d3a154461d449/file-IYRmmDJYWl.gif)
