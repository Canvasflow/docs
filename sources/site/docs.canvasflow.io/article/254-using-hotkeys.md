# Using Hotkeys

When in the 'Article Editor' there are a number of hotkeys available to speed up content creation or display component information.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5d9c57cb2c7d3a7e9ae235df/file-jy6eou5F31.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5d9c57cb2c7d3a7e9ae235df/file-jy6eou5F31.png)

To start making use of hotkeys, please refer to this list:

| **Function** | **Hotkey** |
| --- | --- |
| Save | `Cmd / Control + S` |
| Publish | `Cmd / Ctrl + P` |
| Delete with no prompt | `Cmd / Ctrl + Delete` |
| Create Gallery | `Cmd / Ctrl + drop image on to image` |
| Create Caption from Text | `Cmd / Ctrl + drop text on to image / gallery` |
| Adds Image to Gallery | `Cmd / Ctrl + drop image on to gallery` |
| Convert to 2x Column | `Cmd / Ctrl + drop text component on existing text component` |
| Display Component Type | `Hold Alt` |
| | <br/><br/> |
