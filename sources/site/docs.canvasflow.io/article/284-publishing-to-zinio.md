# Publishing to Zinio

### To Publish to Zinio:

1. Ensure your 'Issue' has an 'Issue ID' and 'Release Date' set in 'Issue Settings' by navigating to the 'Issue Manager', and selecting the `Settings` icon. 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f80c18502d1120e90d25f/file-E5ZKXvv9cg.png)

2. Specify an 'Issue ID' and 'Release Date' (mandatory fields for Zinio). 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f80b5b3ebfb109b588017/file-Ii7gTW5Tw8.png)

3. Select `Update` .
4. Navigate to ‘Article Manager’ view.
5. Publish all of the articles that want to include in Zinio issue by ticking the checkboxes and then choosing `Publish Selected` in the toolbar. 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f81030a2dae5b58fb5618/file-jOrphTBhei.png)

6. Once the articles are published, click the `Download Prism XML` button in the toolbar. 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f8114b3ebfb109b588018/file-uEJ6OSH3t0.png)

7. When the download completes, you’ll have a Zip file which contains each article in XML format, as well as all images associated with the issue.
8. You can now upload this file to Zinio via their upload tool.
