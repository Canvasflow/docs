# Font Style Variants

'Font Style Variants' are a way to specify the font family for different text types - **Bold**, _Italic_, and _**BoldItalic**_.

For example, a 'Subtitle Component' in ‘Style 1’ is currently using the ‘Roboto-Thin’ font. If content within this component is set to bold (from 'Article Editor'), rather than letting the browser apply a pseudo bold font style, it is possible to instruct the system to instead use the ‘Roboto-Bold’ font. 

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/60351247b3ebfb109b5852ac/file-HKJknxL0b3.png)

**To Set Font Variants:**

1. Enter the 'Style Editor' of your chosen style.
2. Select a `Text Component`.
3. In the properties panel, specify the Bold, Italic and BoldItalic font variants you require.

### Notes

1. To add custom fonts to your publication please find further help [here](https://docs.canvasflow.io/article/14-custom-fonts).

The purpose of this functionality is to avoid [faux browser styles](https://docs.canvasflow.io/article/220-avoiding-faux-browser-styles) which typically produce poor readability on some browsers. It’s strongly recommended that unless basic web safe fonts (Arial, Times New Roman, etc) are being used, a specific font is set for the ‘**Bold**’, ‘_Italic_’ and ‘_**BoldItalic**_’ font variant family fields.
