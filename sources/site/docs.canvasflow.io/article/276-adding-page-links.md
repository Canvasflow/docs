# Adding Page Links

Direct links to other pages within the same issue can be created from both text and images when working with Maz, Paperlit, Pugpig, or PWA brands.

### Creating a page link from an image

1. Within 'Article Editor', select the image you wish to link from.
2. In the 'Image Properties Tab', under ‘Link’, select `Page` . 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f72f10a2dae5b58fb55c9/file-gkbfOrjfbW.png)

3. A list of all articles within the current issue will be displayed.
4. Select the `Article` you wish to link to.
5. Click `Save` to confirm the change.

### Creating a page link from text

1. Highlight the text you wish to link from.
2. Within the 'Text Editor Toolbar' select the `Page Link` button. 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f7353661b720174a72ce8/file-syyIKxUxN2.png)

3. A full list of articles within the current issue will be displayed.
4. Select the article you wish to link to and click `OK` . 
5. Save the article to confirm the change.
