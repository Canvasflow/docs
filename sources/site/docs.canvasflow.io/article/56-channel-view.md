# Working with Channel Views

Once a publishing channel has been configured for a publication, the option to switch to that channel view will be made available in the 'Channel View' menu within the 'Article Manager'_._

When a publishing channel is selected, the article manager will display contextual information associated with that channel.  For example, if connecting to _'Twixl Publisher'_, it will show which articles are published, their current states (published, synced / un-synced, etc) as well as providing options for editing Twixl metadata. 

If you are connected to a channel that support external content types, it will also display these articles.

Selecting the `Default` channel shows all articles that have been created in Canvasflow.  It will not show any externally generated content.
