# Adding Components

Canvasflow offers a full drag and drop interface making it easy to add new components to an article or template.

## What is a Component?

A component can range from a simple text block, to rich media elements and even more complex structural layouts including columns and dividers.  There is no limit to the number of components that can be added to an article with the canvas automatically expanding to accommodate each new one.

#### Adding a Component

1. From the 'Component Panel', click the component type heading you would like to add.  This will display the available components for this type. Find the component that you wish to add.
2. Click and drag the component onto the canvas.  As the component is moved, all valid drop zones will become highlighted to indicate where the component is eligible to be placed. 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5a9434c12c7d3a54cdfcce50/file-bhrvZB7UTu.png)

3. As the component is moved closer to a drop zone, an arrow will be displayed indicating where the component will be placed if dropped. 
4. Release the button to place the component in the desired location.  The component will appear in the selected location.
