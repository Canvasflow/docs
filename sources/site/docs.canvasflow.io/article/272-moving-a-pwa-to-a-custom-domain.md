# Moving a PWA to a custom domain

When an app is ready for production, it can be hosted in a number of different ways. 

These include:

- A subdomain of Canvasflow. (e.g. [https://myapp.canvasflow.io](https://myapp.canvasflow.io)) 
- A custom TLD. (e.g. [https://myapp.com](https://myapp.com))
- A custom subdomain. (e.g. [https://magazine.myapp.com](https://magazine.myapp.com))
- An iframe on an existing website. (Please note that some functionality is lost via this implementation.)

### Note

Contact our support team when you are ready to move your app to production. Please allow 24 hours for this process to complete, although under normal circumstances it will typically take just a few hours.
