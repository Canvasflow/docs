# Adding a XML Channel

### To add a XML Channel:

1. Navigate to the ‘Publication Manager’
2. Mouse over the publication and select the cog icon to enter ‘Publication Settings’ 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f5eb00a2dae5b58fb5507/file-aK2i4DOoKX.png)

3. Select the ‘Publish Channels’ tab
4. Select the ‘Add New’ icon
5. Enter a Channel Name and select Prism XML in the ‘Channel Selector’ drop down
6. Select ‘Add Channel’
