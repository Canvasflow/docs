# Output as XML

### To output as XML:

1. Navigate to ‘Article Manager’ view.
2. Publish all the articles which are to be output by ticking the required checkboxes and then clicking `Publish Selected` in the toolbar. 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f82d1b3ebfb109b588025/file-SpEcoPFuAj.png)

3. Once the articles are published, click `Create Prism XML` in the menu bar.

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f8114b3ebfb109b588018/file-uEJ6OSH3t0.png)

4. When the download completes, you’ll have a Zip file comprised of each article in XML format, as well as all images associated with the issue.
