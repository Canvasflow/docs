# The Article Navigator

The 'Article Navigator' allows you to quickly and easily switch between articles without having to leave the editor.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5e18628004286364bc93b8ae/file-Ctd53PN6p5.gif)

To use the 'Article Navigator':

1. Save your current article.
2. In the 'Article Builder' select the `Navigator` icon next to the 'Article Manager' button.
3. A dropdown menu displays all articles within the current publication.
4. Select an article to switch to it.

#### Display as Grid

The 'Display as Grid' option changes the navigator dropdown into a grid-format, which may be easier to navigate for publications with lots of content.
