# Duplicating a Style

_Styles can easily be duplicated to produce multiple styles with slight variations._

## Duplicating a style

1. From the 'Style Manager' create a new style.
2. Provide a name, and under 'Source', select `Copy From`.
3. In the 'Existing Style' dropdown, select the style you want to copy from.

## Duplicating styles across publications

If you want to create a duplicate of a style, but place it within a different publication, use the 'Style Type' function which is fully explained [here](https://docs.canvasflow.io/article/244-publication-and-global-styles). If you're already familiar with style types, follow these steps:

1. Navigate to the 'Style Manager', set the style that you want to make a copy of to `Global`.
2. Navigate to the publication you want the copy to be created in.
3. Create a new style.
4. Provide a name.
5. Under the 'Source' option, select `Copy From`, then select the style from step 1.
6. Select `OK`. You now have a duplicate of the original style.
7. Navigate back to the 'Style Manager' of the publication the global style **originated** from.
8. Change the global style's 'Scope' back to `Publication`.
