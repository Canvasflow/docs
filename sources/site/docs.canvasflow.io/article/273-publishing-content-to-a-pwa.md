# How to publish content to a PWA

Publishing content to a PWA is a simple two-step process.  Step one is to publish the article(s) that will be included in an issue. Step two is to ‘release’ the issue.

### Note

1. It is important to remember that issues and articles are not publicly available until an issue is ‘released’ (see step 2).

### Publishing Content

1. Navigate to ‘Issue Manager’ and open the issue you want to publish.
2. From ‘Article Manager’, ensure the channel view is set to ‘PWA Channel’.
3. You now need to select the articles to be published.  You can do this in two ways:
 1. **Individually:** Within the 'Article Manager' you can publish articles using the `Publish` icon found next to each article. 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f681b0a2dae5b58fb5564/file-0xEbsKJg71.png)

 2. **Multiple:** By selecting several articles using the checkboxes, multiple articles can be published at once. 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f6800b3ebfb109b587f66/file-IluIJt0nPV.png)

4. If a currently published article is edited, it becomes _'out of sync’_ with the current live version. This is indicated by the publish button turning orange. To update the live version, click `Publish` to update the article and resync with its new content. 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f68a50a2dae5b58fb5568/file-e57Hz9VhaA.png)

5. If changes have been made to multiple articles, you can update all changes simultaneously using the ‘Publish Issue’ button. Please note this will only update currently published articles. 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603f68ecb3ebfb109b587f6e/file-OsPaFS3lSY.png)
