# Changing the Current Style

As styles are managed independently from articles, it's possible to change the article's current style at any time. This can be achieved in two ways, either via 'Article Manager' or 'Article Builder'. 

### Changing a style from 'Article Manager'

This method is useful when you need to change the style of multiple articles simultaneously and you are already confident that the style chosen will not adversely affect the design of the article.

1. Enter 'Article Manager'. A list of all existing articles will be displayed.
2. Select the `Edit` menu by clicking on the `Settings` icon next to your chosen article.
3. Choose `Edit item` to display 'Article Properties'. 

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/603fbcf3b3ebfb109b588258/file-38lEsSqLch.png)

4. To change styles, enter the `Style` menu and select from the list.
5. To save changes, press `OK` . The article is now updated with your new style choices.

### Changing a style from 'Article Builder'

You'll want to use this method when visualising how a new style affects the current design is an important consideration.

1. Choose the article you want to edit.  'Article Builder' will appear.
2. From 'Article Toolbar', click the `Style menu` at the top right and select the style you wish to apply.

 ![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5a903e9b2c7d3a54cdfcbdcd/file-qQk8TnVzcV.png)

3. Once the new style has been applied, click outside of the style menu to close the panel.
4. Click `Save` to apply the style change.

### Editing a style from 'Article Builder' in 'Article View'

When selecting `Edit` on a style from 'Article Builder', you'll be taken to 'Article View'. This view is slightly different to what you may have used in 'Style Manager'. It allows you to edit the style in context of the content you're currently working on:
