# Editing a Style

### Overview

Once a style has been built, its properties can be edited at any time. 

Step by step

1. Navigate to 'Style Manager' and locate the style you wish to edit.
2. From the 'Options' column, click the `Settings` icon. The 'Edit style' window will be displayed.
3. Edit the information in the following fields.
 1. **Title:** edit the title as required.
 2. **Description:** edit the description as required
 3. **Scope:** Choose from `Publication` (accessible by the current brand only) or`Global`(accessible by all publications within the account). Publication is the recommended option for most cases, more information is available [here](https://docs.canvasflow.io/article/244-publication-and-global-styles).
 4. **Tablet:** (optional) Define how this style will display on tablet style devices.
 5. **Desktop:** (optional) Define how this style will display on traditional browsers. Further information on 'Device Styles' is available [here.](https://docs.canvasflow.io/article/293-device-styles)
4. Click `Update` to apply changes.

### Editing a style from 'Article Builder'

1. Open an article in the editor.
2. Select the `Styles` dropdown menu.
3. Click `Edit` next to your chosen style.
4. You'll be taken to the style editor in 'Article View' mode.

 [![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/6034e76d24d2d21e45ed92b5/file-ijC2MunfSY.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/6034e76d24d2d21e45ed92b5/file-ijC2MunfSY.png)

5. The 'Article View' mode allows you to edit the style of components in context of the content you're working on.  
6. Click the component you wish to edit to reveal the style properties. 
7. To switch back to the 'Default View', select 'Switch to Default View' at any time.
