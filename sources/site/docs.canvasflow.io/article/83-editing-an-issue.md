# Editing an Issue

1. Navigate to the publication which contains the issue you wish to edit.
2. Locate the issue you wish to edit.
3. Click the `More Options` menu and select `Edit`. An 'Edit Article' window will be displayed.
4. Make the required changes and click `Update` to apply.
