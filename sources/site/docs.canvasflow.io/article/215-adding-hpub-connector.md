# Adding HPub connector

Adding a HPub (HTML Publication) connector allows you to create an entire issue in rich and responsive HTML format.

#### To add a HPub connector:

1. From 'Brand Manager', select the publication you wish to add a connector to and click the `Settings` button. 
2. Go to 'Publish Channel' and click the `+` button
3. Select `HPub` .
4. Enter a name for the channel and select `Add Channel` .
5. Navigate to 'Article Manager'. 
6. Next, you need to [download a HPub file](https://docs.canvasflow.io/article/217-downloading-hpub-file).
