# Custom URL Schemes - Linking to content

When connected to a Twixl Publisher channel, there exist a number of custom URL schemes which enable you to link to a particular collection, article or even an article within a collection.

### Linking to a Twixl Publisher content item 

To link to a Twixl content item within a collection, the link must start with ' **tp-collection://'**

For example, to link to to an article within a collection, the following URL Scheme would be used:

**'tp-collection://TWIXL-COLLECTION-NAME/TWIXL-ARTICLE-NAME'**

Or link to an article within the same collection:

**'tp-pagelink://TWIXL-ARTICLE-NAME'**

You can find  [more information here](https://goo.gl/puzT85) regarding Custom URL Schemes for article-based Twixl apps.
