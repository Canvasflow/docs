# Building a Template

The 'Template Builder' works in exactly the same way as the 'Article Builder'. Once you've created a template, it can be edited by selecting it from the 'Template Manager'.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5a9432ce2c7d3a54cdfcce37/file-xeglHrjh06.png)

### Building a Template

1. Once a template has been created, click `Edit` to load the 'Template Builder'. 
2. As with building an article, drag and drop the desired components onto the canvas, make any required edits to the components as you go.
3. When the template is complete, select `Save` from the toolbar.
4. This template will now be shown as an option the next time you [create an article](https://docs.canvasflow.io/article/73-creating-an-article).

### Note:

1. 'Styles' are **separate** to templates. Styles are used to set fonts, colours, padding, etc.
2. Templates contain only the basic component structure and initial content for an article.
