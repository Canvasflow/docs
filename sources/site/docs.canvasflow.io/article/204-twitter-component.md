# Twitter Component

The Twitter (now known as X) component allows you to embed the feed of any Twitter account by simply entering the Twitter handle into the top field.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/571df1d49033600cce434499/images/5b69af132c7d3a03f89d6ee5/file-dzVL4okfbs.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/571df1d49033600cce434499/images/5b69af132c7d3a03f89d6ee5/file-dzVL4okfbs.png)

#### Fixed Height

By default, a Twitter feed will display the last 20 tweets, which can take up a significant height in an article.  Enabling 'Fixed Height' allows you to control the height of the Twitter component, adding a scroll bar for users to navigate through tweets.

#### Display on Device

The 'Display On' option allows you to decide which devices an image appears on. The default is that Twitter content will be shown to readers across every device type.
